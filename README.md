# Мои Финансы · Family Finance v1

Адаптивное PWA для семейного учёта денег. React + Vite + IndexedDB (Dexie) + Google Apps Script / Google Sheets + GitHub Pages. Работает на телефонах, планшетах и ПК.

## Что работает на устройстве

- Создание семьи и локальный вход каждого члена по отдельному PIN (PBKDF2-верификатор)
- Личные и общие счета: наличные, дебетовые карты, накопления, кредитные/долговые счета
- Доходы, расходы и переводы с точными целыми копейками, UUID и историей автора
- Бюджеты по категориям, графики и отчёты по месяцам
- Кредиты и кредитные карты со связанными долговыми счетами, оценкой срока выплат
- Долги, финансовые цели, история и CSV-экспорт
- Тёмная тема, адаптивная сетка от телефона до ПК, режим скрытия сумм
- Напоминание в интерфейсе в заданный час, если у участника сегодня нет операций; уведомление браузера при активном PWA (после согласия)
- Офлайн-хранение IndexedDB, очередь исходящих операций, сохранение ссылки Apps Script по URL или QR

## Важное ограничение до подключения реальной БД

**Эта сборка не является полностью подключённой финансовой системой.** Операции сохраняются **локально**, но обмен с Google Sheets пока не активен. PIN локальный, а содержимое IndexedDB не зашифровано; серверная проверка прав не используется мобильным клиентом. Ссылка на Apps Script сохраняется, но сама по себе не означает синхронизацию. Не используйте эту сборку для хранения конфиденциальных финансовых данных до завершения защищённого подключения, миграции и проверок.

Серверные файлы включают схему БД, `rpc` с проверкой PIN и сессии, idempotent `postTransaction`, `Bridge.html` для защищённого обмена через HtmlService и почтовые напоминания. **Привязка мобильного клиента к этому API ещё не выполнена.** Важно не выдавать его за готовую синхронизацию.

## Локальный запуск

```bash
npm install
npm run dev
npm run build
```

Для GitHub Pages: Settings → Pages → Build and deployment → Source: **GitHub Actions**. Workflow `.github/workflows/pages.yml` соберёт и опубликует `dist` на `https://morkov-d.github.io/family-finance-pwa/` после успешной сборки.

## Подготовка Google Apps Script через clasp

```bash
npm install
npx clasp login
cp .clasp.json.example .clasp.json
# Укажите scriptId существующего проекта Apps Script
npm run gas:push
```

`clasp push` **обновляет исходники выбранного проекта**. Проверьте scriptId и сделайте резервную копию перед запуском на проекте с данными. `.clasp.json` игнорируется Git.

В редакторе Apps Script вручную запустите `setupBackend()` — она создаёт отдельную таблицу и вкладки в Google Sheets, записывает её ID в Script Properties. Затем задайте Script Properties `INITIAL_ADMIN_NAME`, `INITIAL_ADMIN_PIN` (6 цифр), `INITIAL_ADMIN_EMAIL` (по желанию), запустите `bootstrapOwner()`. Не записывайте PIN/токены в Git и не публикуйте в комментариях. Укажите `FAMILY_TIMEZONE` (например, `Europe/Moscow`) в свойствах скрипта.

Чтобы включить серверные **email-напоминания**, вручную запустите `installReminderTrigger()` и задайте каждому разрешившему отправку участнику email, `remind_enabled=true` и `remind_hour` в `FamilyMembers` либо через серверный RPC `setReminder` после авторизации. Напоминания запускаются примерно раз в час (фактическое время триггера может отличаться), только если за день не было операций; отправка зависит от квот Google MailApp. Пока данные мобильного клиента не синхронизированы, сервер не знает о локальных операциях, поэтому **не включайте триггер для реального использования до подключения синхронизации**.

### План завершения серверной интеграции

1. Привязать профили мобильных устройств к существующим профилям `FamilyMembers`, без потери UUID и локальных операций.
2. Подключить `Bridge.html` через iframe/`postMessage` и `google.script.run` (вместо небезопасного JSONP), протестировать поведение Safari и Google OAuth.
3. После PIN-авторизации выполнять безопасные `snapshot`/`postTransaction`, сверку версий, учёт частичных ошибок, подтверждение каждой операции и восстановление очереди.
4. Добавить зашифрованное локальное хранение с механизмом восстановления и отзыва устройства.
5. Настроить email либо отдельную Web Push-службу для уведомлений при закрытом PWA. Одних Service Worker и `setTimeout` недостаточно.

## Денежная модель

Все суммы — целые копейки. Для долговых счетов остаток отрицателен, погашение основного долга — **перевод** на долговой счёт, проценты — **расход**. Сумма кредитного лимита не считается деньгами. Переводы между своими счетами не увеличивают доходы/расходы. Долги между людьми и финансовые цели — отдельные регистры и сами по себе банковские балансы не меняют.

## Google Apps Script: функции запуска

После `npm run gas:push` в редакторе Apps Script запускайте **`setupBackend`**, затем **`bootstrapOwner`** (после настройки `INITIAL_ADMIN_NAME`, `INITIAL_ADMIN_PIN`), затем **`checkBackend`** и при необходимости **`installReminderTrigger`**. Файл `EntryPoints.gs` содержит эти открытые команды. Все `.gs` файлы должны быть загружены. `ftext_()` — внутренний помощник из серверной версии v2 (`Sync.gs`), не предназначенный для ручного запуска. Если вы используете v2 и видите `ftext_ is not defined`, проверьте наличие `Sync.gs` и выполните `clasp push` повторно.
